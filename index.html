Purpose

Provides accurate, verified information about admissions, courses, departments, facilities, placements, and college services through an intelligent conversational interface.

How it works

Local knowledge base flow

Answers are retrieved from a verified, structured KCE knowledge base that ships with the app.

Local-first

No AWS required. By default the browser answers directly from knowledge/kce-knowledge.js. The optional local Python API in backend/ uses the same knowledge base and is enabled only when API_ENDPOINT is set.
